Utilizando funciones

Las funciones son los principales bloques de construcción del programa. Permiten que el código se llame muchas veces sin repetición.

Declaración de una función básica

Para crear una función podemos usar una declaración de función:

function saludar() {
    alert('¡Hola a todos!');
}

La palabra clave function va primero, seguida del nombre, los parámetros entre paréntesis y el cuerpo de la función entre llaves.
