Ejercicio complementario 3: validación de campos con expresiones regulares.

Investigación: expresiones regulares

Una expresión regular es un patrón que permite comprobar la forma de una cadena. En JavaScript se utiliza el método test() para saber si el texto coincide con el patrón.

  • ^ indica inicio y $ indica final del texto.
  • [A-Z] representa una letra mayúscula y \d un dígito.
  • {n} indica una cantidad exacta de caracteres.
  • + significa una o más repeticiones.

El patrón valida el formato de la fecha; adicionalmente se comprueba que sea una fecha real.
